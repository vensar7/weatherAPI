# Погода рядом

Flutter-приложение показывает текущую погоду, почасовой прогноз и прогноз на пять дней для вашего местоположения.

Координаты запрашиваются у устройства только при использовании приложения. Прогноз загружается из Open-Meteo, API-ключ не требуется.

Запуск из корня проекта:

```sh
flutter pub get
flutter run
```

flutter run -d web-server --web-hostname 0.0.0.0 --web-port 3000
